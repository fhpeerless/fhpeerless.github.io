Linux常用命令大全

前言

工欲善其事必先利其器！人都有遗忘性，必须把以前学的整理，温故而知新，可以为师矣。本笔记整理了Linux系统中最常用的命令，按功能分类，便于查询和使用。

一、文件与目录管理

1. 目录操作

pwd - 显示当前工作目录

功能：输出当前所在的绝对路径

cd - 切换目录

功能：改变当前工作目录

示例：

ls - 列出目录内容

功能：列出目录中的文件和子目录

常用选项：

  • -l：以长格式显示（包含权限、所有者、大小、修改时间等）
  • -a：显示所有文件，包括隐藏文件（以.开头的文件）
  • -h：以人类可读的格式显示文件大小
  • -r：反向排序
  • -t：按修改时间排序

示例：

mkdir - 创建目录

功能：创建新目录

常用选项：

  • -p：递归创建多级目录

示例：

rmdir - 删除空目录

功能：删除空目录

常用选项：

  • -p：递归删除多级空目录

示例：

2. 文件操作

touch - 创建文件或更新时间戳

功能：如果文件不存在则创建空文件；如果文件存在，则更新其访问时间和修改时间

示例：

cp - 复制文件或目录

功能：复制文件或目录

常用选项：

  • -r：递归复制目录及其内容
  • -i：覆盖前提示确认
  • -v：显示复制过程

示例：

mv - 移动或重命名文件/目录

功能：移动文件/目录或重命名

常用选项：

  • -i：覆盖前提示确认
  • -v：显示移动过程

示例：

rm - 删除文件或目录

功能：删除文件或目录

常用选项：

  • -r：递归删除目录及其内容
  • -f：强制删除，无需确认
  • -i：删除前提示确认
  • -v：显示删除过程

示例：

ln - 创建链接

功能：创建文件或目录的链接

  • 硬链接：通过索引节点号（Inode）链接到文件内容，删除源文件后链接仍可访问
  • 软链接：类似于Windows的快捷方式，链接指向源文件路径，删除源文件后链接失效

示例：

二、文件内容查看与处理

1. 文件内容查看

cat - 显示文件内容

功能：显示文件的全部内容

常用选项：

  • -n：显示行号
  • -b：显示非空行的行号

示例：

less - 分页查看文件内容

功能：分页显示文件内容，支持上下滚动和搜索

常用操作：

  • 空格键：向下翻页
  • b：向上翻页
  • /关键词：向下搜索关键词
  • ?关键词：向上搜索关键词
  • n：查找下一个匹配项
  • N：查找上一个匹配项
  • q：退出

示例：

head - 显示文件开头

功能：显示文件的前几行内容

常用选项：

  • -n <行数>：显示指定行数的内容（默认10行）

示例：

tail - 显示文件结尾

功能：显示文件的最后几行内容

常用选项：

  • -n <行数>：显示指定行数的内容（默认10行）
  • -f：实时跟踪文件内容变化（常用于日志监控）

示例：

2. 文件内容搜索与处理

grep - 在文件中搜索匹配的行

功能：在文件中搜索包含指定模式的行

常用选项：

  • -i：忽略大小写
  • -n：显示匹配行的行号
  • -v：显示不匹配的行
  • -r：递归搜索目录下的所有文件
  • -A <行数>：显示匹配行及其后的指定行数
  • -B <行数>：显示匹配行及其前的指定行数

示例：

sed - 流编辑器，用于文本替换和处理

功能：对文件内容进行替换、删除、插入等操作

常用选项：

  • -i：直接修改文件内容（否则仅显示修改结果）
  • -e：执行多个sed命令

示例：

awk - 文本处理工具，用于数据提取和报告生成

功能：按行处理文本文件，支持字段提取、条件判断和计算

示例：

wc - 统计文件的字节数、字数、行数

功能：统计文件的行数、字数、字节数等信息

常用选项：

  • -l：统计行数
  • -w：统计字数
  • -c：统计字节数
  • -m：统计字符数

示例：

三、权限管理

1. 文件权限查看

ls -l - 查看文件权限

功能：显示文件的详细信息，包括权限、所有者、所属组等

权限表示格式：rwxrwxrwx

  • 前三位：文件所有者的权限
  • 中间三位：文件所属组的权限
  • 后三位：其他用户的权限

权限含义：

  • r：读权限（4）
  • w：写权限（2）
  • x：执行权限（1）
  • -：无权限（0）

示例：

2. 权限修改

chmod - 修改文件或目录的权限

功能：修改文件或目录的访问权限

权限表示方式：

  • 数字表示法：如755、644
  • 符号表示法：如u+x、g-w、o=r

数字权限计算：

  • r=4, w=2, x=1, -=0
  • 所有者权限 + 所属组权限 + 其他用户权限

示例：

chown - 修改文件或目录的所有者和所属组

功能：修改文件或目录的所有者和所属组

常用选项：

  • -R：递归修改目录及其内容的所有者和所属组

示例：

chgrp - 修改文件或目录的所属组

功能：修改文件或目录的所属组

常用选项：

  • -R：递归修改目录及其内容的所属组

示例：

四、系统信息与管理

1. 系统信息查看

uname - 显示系统信息

功能：显示系统的基本信息

常用选项：

  • -a：显示所有系统信息（内核名称、主机名、内核版本、内核发布日期、硬件架构等）
  • -r：显示内核版本
  • -m：显示硬件架构

示例：

hostname - 显示或设置主机名

功能：显示或设置系统主机名

示例：

uptime - 显示系统运行时间和负载

功能：显示系统运行时间、用户数和系统负载

示例：

free - 显示内存使用情况

功能：显示系统内存和交换分区的使用情况

常用选项：

  • -h：以人类可读的格式显示
  • -m：以MB为单位显示
  • -g：以GB为单位显示

示例：

df - 显示磁盘使用情况

功能：显示文件系统的磁盘使用情况

常用选项：

  • -h：以人类可读的格式显示
  • -T：显示文件系统类型

示例：

du - 显示目录或文件的磁盘使用空间

功能：显示目录或文件的磁盘使用空间

常用选项：

  • -h：以人类可读的格式显示
  • -s：仅显示总计
  • -c：显示总计并添加总和行

示例：

top - 实时显示系统进程信息

功能：实时显示系统的进程状态，包括CPU、内存使用情况和进程列表

常用操作：

  • P：按CPU使用率排序
  • M：按内存使用率排序
  • N：按进程ID排序
  • k：终止指定进程
  • q：退出top

常用选项：

passwd - 设置用户密码

userdel - 删除用户

常用选项：

示例：

groupadd - 创建新组

功能：创建新的用户组

示例：

groupdel - 删除组

功能：删除用户组

示例：

usermod - 修改用户属性

功能：修改用户的属性，如所属组、shell、主目录等

常用选项：

  • -aG：将用户添加到指定的附加组
  • -s：修改用户的登录shell
  • -d：修改用户的主目录

五、网络命令

1. 网络连接测试

ping - 测试网络连接

功能：测试与目标主机的网络连接是否正常

常用选项：

  • -c <次数>：发送指定次数的ICMP包后停止
  • -s <大小>：设置ICMP包的大小

示例：

curl - 发送HTTP请求并获取响应

功能：发送HTTP/HTTPS请求，下载或上传文件

常用选项：

  • -O：将远程文件下载到本地，保持文件名不变
  • -L：跟随重定向
  • -I：仅显示HTTP头信息
  • -X：指定HTTP请求方法（GET、POST、PUT等）
  • -d：发送POST请求的数据

示例：

wget - 下载文件

功能：从网络上下载文件

常用选项：

  • -O <文件名>：指定下载文件的保存名称
  • -c：断点续传
  • -r：递归下载整个网站

示例：

2. 网络配置与信息

ifconfig - 显示或配置网络接口（较旧的命令）

功能：显示或配置网络接口的IP地址、子网掩码、MAC地址等信息

示例：

ip - 网络配置工具（替代ifconfig的新命令）

功能：显示或配置网络接口、路由表、ARP表等

常用命令：

  • addr：显示或配置IP地址
  • link：显示或配置网络接口
  • route：显示或配置路由表

示例：

netstat - 显示网络连接、路由表、接口统计等

功能：显示网络连接、路由表、接口统计、伪装连接和多播成员等信息

常用选项：

  • -t：显示TCP连接
  • -u：显示UDP连接
  • -l：显示监听状态的连接
  • -n：使用数字形式显示地址和端口号
  • -p：显示进程ID和进程名

示例：

ss - 显示套接字统计信息（替代netstat的新命令）

功能：显示网络套接字的详细信息，比netstat更快更高效

常用选项：

  • -t：显示TCP套接字
  • -u：显示UDP套接字
  • -l：显示监听状态的套接字
  • -n：使用数字形式显示地址和端口号
  • -p：显示进程ID和进程名

示例：

六、进程管理

1. 进程查看

ps - 显示进程状态

功能：显示当前进程的状态

常用选项：

  • aux：显示所有用户的所有进程（BSD风格）
  • -ef：显示所有进程的完整信息（System V风格）
  • -l：显示长格式输出

示例：

top - 实时显示进程动态（详见系统信息部分）

htop - 交互式进程查看器（需要安装）

功能：交互式显示进程动态，比top更强大（需要先安装：sudo apt install htop）

2. 进程控制

kill - 终止进程

功能：向进程发送信号，默认发送TERM信号（终止进程）

常用信号：

  • -9或-SIGKILL：强制终止进程
  • -15或-SIGTERM：优雅终止进程（默认）
  • -1或-SIGHUP：重新加载配置

示例：

nohup - 在后台运行命令，忽略挂断信号

功能：在后台运行命令，即使关闭终端也能继续运行

示例：

jobs - 显示当前终端的后台作业

功能：显示当前终端的后台作业列表

示例：

fg - 将后台作业切换到前台

功能：将后台运行的作业切换到前台运行

示例：

bg - 将前台作业切换到后台

功能：将暂停的作业切换到后台继续运行

示例：

九、常用快捷键

快捷键 功能
Ctrl + C 中断当前命令
Ctrl + Z 暂停当前命令，放入后台
Ctrl + D 退出当前终端或shell
Ctrl + L 清屏
Ctrl + A 移动光标到行首
Ctrl + E 移动光标到行尾
Ctrl + U 删除光标前的所有字符
Ctrl + K 删除光标后的所有字符

Tab 自动补全命令或文件名
↑ / ↓ 浏览命令历史
Ctrl + R 搜索命令历史

十、注意事项

  1. 谨慎使用root权限：使用sudo命令时要格外小心，避免误操作导致系统问题
  2. 备份重要数据：在执行可能导致数据丢失的命令前（如rm -rf），确保已备份重要数据
  3. 注意路径：执行文件操作命令时，要注意当前工作目录和目标路径
  4. 查看命令帮助：使用命令 --help或man 命令查看命令的详细用法
  5. 网络安全：不要在生产环境中使用弱密码，定期更新系统和软件包
